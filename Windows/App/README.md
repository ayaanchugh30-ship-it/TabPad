# Windows configuration app

This folder is reserved for the future WinUI 3 configuration app. It will mirror the macOS controls:

- Tablet-mode enable/disable
- Display selection
- Interactive active-area editor
- Percent and millimeter inputs
- Aspect-ratio lock and centering
- Jitter-filter controls
- Selected touchpad identity and hardware diagnostics

The app depends on a working TabPad Windows kernel driver; it cannot read global one-finger Precision Touchpad contact coordinates by itself.
